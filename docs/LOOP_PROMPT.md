# 🔁 TDD 開發提示(手動觸發版)

> ⚠️ 本環境**不支援自動排程**(無法用 `/loop` 每 30 分鐘自動觸發),
> 所以改成「一次觸發、連續做多個任務」的寫法。你想繼續時再手動送一次即可。

在**新對話視窗**(建議用 Sonnet 4.6)複製下面整段貼上即可。

> 開始前先確認:已切到分支 `claude/project-review-corrections-b8lkqt`,
> 並已執行 `pip install -r backend/requirements.txt`。

---

## 直接貼這段

```
依 TDD 連續開發 PhotoFlow AI,直到卡關或完成約 3–5 個子任務:
每個子任務的循環:
(1) 讀 docs/ROADMAP.md,挑下一個還沒打勾、且不需要外部 API 金鑰或人工申請
(Meta 審核、Stripe 帳號、找人測試等)就能寫的最小子任務。
(2) 嚴格 TDD:先在 backend/tests 寫一個會失敗的測試,跑 pytest 確認紅燈;
再寫最少的程式讓它綠燈,必要時重構,全程保持其他測試也綠。優先寫不需要
真實資料庫/網路的純邏輯測試,外部服務一律用 mock。
(3) 全綠後把該任務在 ROADMAP 打勾,用清楚訊息 git commit,push 到
claude/project-review-corrections-b8lkqt 分支。
(4) 接著做下一個子任務,重複以上。完成約 3–5 個、或卡在需要金鑰/人工的
步驟時停下,回報這輪做了什麼、下一步卡在哪。結束前絕不留紅燈或無法編譯的程式碼。
```

## 要做下一批時

直接回一句 **`繼續`** 就好;若視窗已開很久、它好像忘了脈絡,就**把上面整段再貼一次**
(因為它每次都重讀 ROADMAP,所以會自動接續進度,不會重做)。

---

## 設計重點

| 設計 | 原因 |
|------|------|
| 不用 `/loop`,改一次做多個任務 | 本環境無法自動排程,手動觸發一次就要盡量多做 |
| 讀 ROADMAP 挑下一個 | 讓它自己找進度,重貼也不會重做同一件事 |
| 只寫不需金鑰/人工的任務 | 申請 Meta 權限、開 Stripe、找人測試等 Agent 做不了,自動跳過 |
| mock 外部服務、優先純邏輯測試 | 否則測試會因沒有 Postgres/網路而紅燈 |
| 完成 3–5 個就停下回報 | 避免單次跑太長、脈絡爆掉;也方便你檢查方向 |
| 結束不留紅燈 | 每次停手都是乾淨可提交狀態,中斷也安全 |

## 提醒

- 新視窗記得切到同一分支,並先安裝後端套件,否則第一批會卡在缺套件。
- Sonnet 4.6 跑 TDD 很合適;若遇到較複雜的架構決策,可手動切回 Opus 處理完再續。
